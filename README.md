# Dion Ben Fernandes Portfolio

Editorial portfolio built with Next.js, React, and TypeScript. Project content is local and statically rendered; proposed concepts are intentionally separated from completed work.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

- Set `NEXT_PUBLIC_SITE_URL` to the confirmed production origin so metadata and `sitemap.xml` use the correct domain.
- Confirm `dionbf.dev@gmail.com` is the intended public email address.
- Add verified LinkedIn and GitHub profile URLs if they should be public.
- Add a current PDF resume only after checking its contents and removing any details not meant for this site.
- Replace proposed project concepts with completed work only after repositories, demos, and evidence are available.

No phone number, employer screenshots, confidential data, project metrics, or unverified profile URLs are included.
